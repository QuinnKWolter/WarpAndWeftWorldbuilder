## Graph and manuscript follow-up

The workspace adds 192 previewed/category-filtered/searchable/favorite icons, full-card tinting, configurable incoming/outgoing anchors (one to four each), empty-canvas connection creation, immediate Delete with undo, explicit unfollow, and full-window focus modes for both drawers, graph and manuscript. Bulk entity descriptions work with both default-only and explicit-facet row formats. The searchable 126-term glossary covers all systems. Notes and reference nodes travel in existing JSON metadata/documents; no database migration is needed.

## Explicit boundaries

This is a distributable single-user alpha. It is suitable for private local/self-hosted testing, not an authenticated public multi-user service. JSON is the portable package; ZIP assets are optional and deferred. Timelines use finite scalar points plus arbitrary author labels rather than assuming a calendar. Entity existence intervals, travel-duration simulation, automatic interpretation of prose, full spatial accessibility, and large-project browser performance certification remain future work.

Scenes resolved as entities or events keep their narrative envelope so sequence and prose do not disappear. A merge joins writing rather than silently replacing it. Undo preserves subsequent prose; if merged prose is edited before undo, the writer may need to reconcile overlapping passages in the restored moments.

No control claims to provide unimplemented AI, attachments, collaboration, publishing, or inline autocomplete. These boundaries are also listed in the README and roadmap.
