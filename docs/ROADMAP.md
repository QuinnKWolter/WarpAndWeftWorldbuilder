# Roadmap

## Next hardening work

- Incremental project transactions and isolated prose saves for very large manuscripts.
- Broader browser performance profiling with hundreds of visible scenes and thousands of modeled changes.
- More accessible spatial graph navigation and tablet device testing.
- Inline mention autocomplete and live reference cleanup when prose mentions are removed.
- More detailed conflict review when merging multiple established narrative objects.
- Entity lifetime intervals and richer fictional-calendar input.
- Asset attachments and a ZIP package that includes those assets.

## Narrative tools

Add knowledge, possession, POV, location, and causality projections using the shared domain model. Expand deterministic diagnostic rules for tracked durations, location conflicts, explicit setups/payoffs and gaps in appearances. Keep findings explainable and navigable.

## Optional assistance

Implement server-only local/generic OpenAI-compatible providers using a selected scene/state context. Review suggestions before applying them. Core writing and graph operations will continue to work offline from third-party services.

## Deferred

No public plugin SDK, social features, marketplace, real-time collaboration, OAuth ecosystem, native mobile application, full manuscript compile system, graph database migration, or complex simulation engine is planned for the initial alpha. Future hosted multi-user operation requires explicit ownership enforcement and authentication.
